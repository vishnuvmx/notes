## Executive Summary & Root-Cause Patterns

Across the codebase, almost all visual glitches and behavioral bugs trace back to **6 systemic root causes** introduced over iterative sessions:

1. **Global `InputDecorationTheme` Leakage**: [`AppTheme.lightTheme`](file:///d:/edita-android/notes/lib/core/theme/app_theme.dart#L99-L118) and [`AppTheme.darkTheme`](file:///d:/edita-android/notes/lib/core/theme/app_theme.dart#L259-L278) define `filled: true` and `focusedBorder: OutlineInputBorder(borderSide: BorderSide(color: ..., width: 1.5))`. Whenever a screen wraps a `TextField` inside a custom pill/box `Container` and only sets `border: InputBorder.none` (omitting `focusedBorder: InputBorder.none`, `enabledBorder: InputBorder.none`, `filled: false`), focusing the field draws a dark rounded border *inside* the outer container (double border).
2. **Global `BottomSheetThemeData(showDragHandle: true)` + Manual Drag Handles**: [`AppTheme`](file:///d:/edita-android/notes/lib/core/theme/app_theme.dart#L136-L143) enables Material 3's native drag handle globally, while 6 bottom sheets also build their own `Container(width: 36, height: 4)` drag handle—rendering **two stacked drag handles** at the top of every modal.
3. **Inconsistent Android Edge-to-Edge Bottom Sheet Insets**: Sheets mix `MediaQuery.viewInsetsOf(context).bottom` (keyboard only), `MediaQuery.viewPaddingOf(context).bottom` (system gesture bar), `useSafeArea: true`, and `SafeArea(bottom: true)` inconsistently—either clipping primary action buttons under the Android gesture bar when the keyboard is closed, or applying double bottom padding.
4. **`NoteEditorScreen` Single-Route State Without Mode-Aware `PopScope`**: Read mode and Edit mode share [`NoteEditorScreen`](file:///d:/edita-android/notes/lib/ui/screens/editor/note_editor_screen.dart#L99-L100) via `bool _isEditingMode`, but [`PopScope`](file:///d:/edita-android/notes/lib/ui/screens/editor/note_editor_screen.dart#L1656-L1664) sets `canPop: !_isSearching` and [`_handleBackPress()`](file:///d:/edita-android/notes/lib/ui/screens/editor/note_editor_screen.dart#L281-L290) calls `Navigator.of(context).pop()`, bypassing Read mode and popping straight to Home.
5. **Visual Table Editor Verbatim Markdown Split & Single-Line Fixed-Width Cells**: [`MarkdownTableService.parseTableLines`](file:///d:/edita-android/notes/lib/domain/services/markdown_table_service.dart#L73-L102) keeps raw `**bold**` asterisks inside cell strings, and [`MarkdownTableEditorSheet`](file:///d:/edita-android/notes/lib/ui/components/dialogs_sheets/markdown_table_editor_sheet.dart#L239-L380) puts single-line `TextField`s inside `width: 148` boxes, truncating `**Primary Language**` into `**Primary Language*`.
6. **Home Screen Control Proliferation**: 4 separate ways to create a note on the same screen, 3 places to open Today's Note, 2 places to open Knowledge Graph, and the deprecated Grid/List toggle in 3 files.
